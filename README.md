# Exo Genesis

A browser base-building RTS with a strategy layer — Command & Conquer meets Civilization, in one solar system. You are the caretaker AI of humanity's last seed-probe:
land on an alien world, keep the cryo-bays alive, and raise the next generation.

Built with Three.js + TypeScript. Design: [docs/DESIGN.md](docs/DESIGN.md).

Status: design phase — Milestone 0 (foundations + zoom prototype) next. One solar system, two acts.
